# paper_longNMP

Code accompanying the manuscript:

> *Long-term ex vivo normothermic perfusion reveals dynamic transcriptional
> reorganisation of human colorectal liver metastases* (in preparation).

This repository contains the R scripts used for differential expression
analysis (DESeq2), pathway enrichment (clusterProfiler, GSVA/ssGSEA) and
data visualisation.

## Data availability

Raw RNA-sequencing data are available at the NCBI Sequence Read Archive (SRA)
under BioProject accession
[PRJNA000000](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA000000)
(BioSample records SAMN000000–SAMN000000; n = 34).

## Requirements

R ≥ 4.5.2. Main packages: DESeq2, sva, ashr, clusterProfiler, GSVA, msigdbr,
tximeta, org.Hs.eg.db, ComplexHeatmap.
